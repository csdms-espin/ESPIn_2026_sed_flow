## ESPIn_2026_sed_flow

# Synopsis
Sed_flow is a simple model that couples Landlab components to vary discharge and sediment flux in a river system. This model simulates event based flows and sediment pulses generated by flow and analyzes how the river channel changes.

First, we generate a grid with an outlet in the lower left corner (0,0), in order to create a single drainage basin. Then, we uplift the grid and run the FlowAccumulator and FastScapeEroder to create a fluvial landscape with one drainage basin for your chosen amount of time.

Next, we use the Space component to drape a layer of soil over the landscape, at your chosen thickness. We then run Space for your choice of timesteps to erode and redeposit the soil. 1) We run Space with constant rainfall, and 2) We run Space varying rainfall according to a time series, via the FlowAccumulator component. 

After running Space with constant and variable rainfall, we visualize the results with grids showing the topographic elevation at the initial and final timesteps, and the channel longitudinal profile during the initial and final timesteps. 

Finally, in step 3, we visualize both scenarios (1, constant rainfall, and 2, variable rainfall), to compare the differences. T

The user can vary many parameters to test how the landscape responds, including initial uplift, bedrock and soil erodibility initially and during the Space run, soil thickness, model run time, rainfall event distribution, and more. 

# Installation instructions
Sed_flow uses Landlab along with several components including FlowAccumulator, DepressionFinderAndRouter, Space, FastscapeEroder, and ChannelProfiler. To install Landlab, use: pip install landlab. For a full description of how to install Landlab, including using mamba/conda, please see the Landlab documentation.
